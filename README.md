***DAMN-Q***
=====================
A discrete-event, modular, lossy and noisy quantum network simulator!

> **Status note:** The tutorial demonstrates component wiring and event flow. Its `00`/`11` counts show Z-basis correlations. Entanglement swapping is under repair, and the simulator's current output should not be used to validate end-to-end entanglement.

Please check the [Tutorial](./Tutorial.ipynb). Don't be shy!
